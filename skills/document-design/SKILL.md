# 문서 디자인 양식

새 문서를 만들 때 이 양식을 따른다. 사용자가 참고 문서를 올리면 그 문서의 디자인을 참고해 만든다.

## 언제 쓰나

- 사용자가 새 문서를 요청할 때.
- 쓰지 않는 경우:
  - 카드뉴스 같은 콘텐츠(SNS 이미지, 캐러셀, 광고 소재 등)에는 자동으로 적용하지 않는다. 사용자가 이 양식을 직접 요청하면 그때만 적용한다.
  - 이미 만든 문서는 사용자가 요청할 때만 이 양식으로 고친다.

## 기본 규칙

1. **색**: 흑백을 기본으로 한다. 회색은 배경에만 쓴다.
2. **글꼴**: Helvetica를 기본으로 한다. 쓸 수 없으면 비슷한 산세리프체를 쓴다.
   - 예(HTML): `font-family: Helvetica, "Helvetica Neue", Arial, sans-serif;`
3. **분위기**: American Apparel 인쇄물처럼 간결하고 명료한 느낌을 따른다. 분위기만 참고하며, 그 브랜드의 로고, 광고 사진, 문구, 상표는 쓰지 않는다.
4. **우선순위**: 장식보다 읽기 쉬운 글자 크기, 여백, 제목과 본문의 위계를 우선한다.
5. **문장**: 문서의 문장은 합니다체로 쓴다. 표의 숫자와 명사구는 그대로 둔다.
   - 예: "자료가 없다" → "자료가 없습니다". 표 칸의 "매출 1,200", "배송 지연"은 그대로 둔다.

## 참고 문서가 올라왔을 때

사용자가 문서를 올리면 그 문서를 이 양식의 디자인 참고로 쓴다.

1. 올라온 문서에서 다음을 살펴본다.
   - **여백**: 페이지 가장자리, 단락과 섹션 사이의 간격.
   - **글자 크기**: 제목 단계별, 본문, 표, 주석의 크기.
   - **제목**: 단계 수, 굵기, 번호 매기는 방식.
   - **표**: 선, 머리행, 정렬, 숫자 표기.
   - **페이지 구성**: 단 수, 표지 유무, 머리말과 꼬리말, 쪽 번호.
2. 본 것을 짧은 목록으로 정리한다. 읽을 수 없는 값은 "확인하지 못함"으로 적고 추측하지 않는다.
3. 새 문서의 여백, 글자 크기, 제목, 표, 페이지 구성은 참고 문서를 따르고, 기본 규칙(색, 글꼴, 문장)은 그대로 지킨다.
4. 정리한 규칙을 이후의 새 문서에도 계속 적용한다. 지속 지침이나 메모리를 쓸 수 있는 환경이면 거기에 저장한다.

## 처음 적용할 때

문서를 만들기 전에, 이번에 적용할 규칙(기본 규칙과 참고 문서에서 가져온 값)을 먼저 짧게 알려 준다.

## 마치기 전 점검

- 글자와 선에 검정과 흰색 말고 다른 색이 쓰이지 않았는가. 회색이 배경 말고 다른 곳에 쓰이지 않았는가.
- 글꼴이 Helvetica(또는 비슷한 산세리프체)인가.
- 제목과 본문의 위계가 글자 크기와 여백으로 분명한가. 장식이 읽기를 방해하지 않는가.
- 문장이 합니다체인가. 표의 숫자와 명사구는 그대로인가.
- 참고 문서가 있었다면 여백, 글자 크기, 제목, 표, 페이지 구성이 반영됐는가.
